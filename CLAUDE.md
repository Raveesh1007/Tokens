# CLAUDE.md

## Absolute rules

1. **Comments:** only single-line comments, and only where they're actually needed. No multi-line comments, block comments (`/* */`), or several comment lines stacked together. If something needs more than one line to explain, rewrite the code so it doesn't.
2. **No Claude attribution:** never add `Co-Authored-By: Claude`, "Generated with Claude Code", or any other Claude/AI credit to commits, PR descriptions, code, docs, or anything else in this repo.
